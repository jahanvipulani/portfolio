Engineering exploration modules

  • Raspberry Pi

    Raspberry Pi is a small, affordable computer used for learning programming and building electronics projects. It is widely used in IoT applications, automation systems, and robotics. It helps students understand hardware and software integration.

  • UI/UX Design

    UI (User Interface) focuses on the look and design of applications, while UX (User Experience) focuses on usability. Good UI/UX ensures that users can interact with a system easily and efficiently. It improves user satisfaction and overall experience.

  • Engineering Ethics

    Engineering ethics involves moral principles that engineers must follow in their work. It ensures safety, honesty, and responsibility in designing and developing systems. Ethical practices help in building trust and protecting society.

  • GitHub & Git Bash

    GitHub is a platform used to store and manage code using version control. Git Bash is a command-line tool that allows developers to use Git commands. Together, they help in collaboration, tracking changes, and managing projects efficiently.
